# 🤖 Machine Learning Algorithm Playground

An interactive Machine Learning visualization web application built with **Streamlit**, **Scikit-Learn**, and **Plotly / Matplotlib**. This playground allows users to tune hyperparameters in real time, generate custom synthetic datasets, and visualize decision boundaries and clustering patterns dynamically.

---

## 🚀 Features

- **Interactive Dataset Generator:** Adjust sample size, noise level, and feature distributions using intuitive UI sliders.
- **Classification Playground:**
  - Support Vector Machines (SVM), Random Forests, K-Nearest Neighbors (KNN).
  - Real-time decision boundary visualizations and accuracy metric evaluation.
- **Clustering Playground:**
  - K-Means & DBSCAN clustering algorithms.
  - Interactive cluster center positioning and data point grouping visualization.
- **Hyperparameter Tuning:** Modify parameters like $K$ values, regularization $C$, tree depth, and distance metrics on the fly.

---

## 🛠️ Tech Stack

- **Frontend / Dashboard:** [Streamlit](https://streamlit.io/)
- **Machine Learning Engine:** [Scikit-Learn](https://scikit-learn.org/)
- **Data Manipulation & Math:** NumPy, Pandas
- **Visualization:** Matplotlib, Seaborn, Plotly
